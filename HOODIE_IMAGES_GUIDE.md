# Škoda GCC Hoodie Images Guide

This guide provides instructions for creating or obtaining the hoodie images required for the Photo Booth application.

## 🎨 Hoodie Design Specifications

Each Škoda GCC hoodie must include the following elements:

### Front Design
- **Location**: Left chest area
- **Content**:
  - Line 1: "Škoda GCC"
  - Line 2: "GCC" (on a separate line below Škoda)
- **Style**: Clean, corporate branding
- **Color**: White text for black/green hoodies, dark text for white hoodie

### Right Sleeve Design
- **Location**: Right sleeve (outer side, near the wrist/forearm)
- **Content**: Minimalistic electronic circuit graphic
- **Style**:
  - Simple circuit board pattern
  - Lines and connection points
  - Tech-inspired, modern look
- **Color**: Matching or contrasting with hoodie color

## 📸 Image Requirements

### Technical Specifications
- **Format**: JPG or JPEG
- **Resolution**: Minimum 1024x1024 pixels (recommended: 2048x2048 or higher)
- **File Size**: Maximum 10MB
- **Quality**: High quality, clear details
- **Background**: Neutral or transparent background preferred

### Photography Guidelines
- Clear, well-lit photo of the hoodie
- Front-facing view showing chest branding
- Side view or detail shot showing right sleeve graphic
- Professional product photography style
- No people wearing the hoodie (for template purposes)

## 🎭 Color Variants

Create three versions of the hoodie:

### 1. Green Hoodie (#4BA82E)
- Classic Škoda brand green
- White text and graphics work best
- Represents the traditional Škoda Auto identity

### 2. Black Hoodie (#000000)
- Professional, sleek appearance
- White or light-colored text and graphics
- Popular choice for formal settings

### 3. White Hoodie (#FFFFFF)
- Clean, modern look
- Dark text and graphics (black or dark gray)
- Fresh, contemporary appearance

## 🖼️ Creating Hoodie Images

### Option 1: Photography
If you have physical hoodies:
1. Set up proper lighting (natural or studio lights)
2. Use a neutral background (white, gray, or green screen)
3. Photograph from multiple angles
4. Edit for color accuracy and background removal
5. Export as high-quality JPG

### Option 2: Digital Design
If creating digitally:
1. Use design software (Photoshop, Illustrator, Canva, etc.)
2. Start with a hoodie template or mockup
3. Add Škoda GCC branding elements:
   - Create text layers for "Škoda GCC"
   - Design electronic circuit graphic
4. Apply appropriate colors for each variant
5. Export as high-quality JPG (1024x1024 or larger)

### Option 3: AI Generation
Use AI image generators with prompts like:
```
Professional product photo of a [GREEN/BLACK/WHITE] hoodie with "Škoda GCC"
text embroidered on the left chest, and minimalistic electronic circuit
graphic on the right sleeve. Clean background, high quality, corporate style,
front view.
```

Recommended AI tools:
- DALL-E
- Midjourney
- Stable Diffusion
- Adobe Firefly

## 📐 Design Templates

### Text Placement (Left Chest)
```
    Škoda GCC
       GCC
```
- Font: Sans-serif, bold
- Size: Proportional to hoodie (approximately 8-12% of chest width)
- Position: Left chest, centered vertically

### Circuit Graphic (Right Sleeve)
```
Minimalistic pattern like:
  ●───●───●
  │   │   │
  ●───┼───●
      │
      ●
```
- Style: Simple lines and nodes
- Size: 3-5 inches on sleeve
- Position: Right sleeve, outer side

## 📂 File Naming Convention

When saving your images, use descriptive names:
- `green_hoodie.jpg` or `skoda_gcc_hoodie_green.jpg`
- `black_hoodie.jpg` or `skoda_gcc_hoodie_black.jpg`
- `white_hoodie.jpg` or `skoda_gcc_hoodie_white.jpg`

## 🚀 Uploading to the Application

Once you have your images:

1. Start the application (backend and frontend)
2. Open the web interface
3. Scroll to the **Admin Panel**
4. For each color:
   - Select the color from dropdown
   - Click "Choose File" and select the JPG
   - Click "Upload [color] Hoodie"
   - Wait for confirmation
5. Verify the hoodie appears in the selector

## 🎯 Quality Checklist

Before uploading, verify:
- [ ] Image is JPG/JPEG format
- [ ] Resolution is at least 1024x1024 pixels
- [ ] File size is under 10MB
- [ ] Škoda GCC branding is visible on chest
- [ ] Electronic circuit graphic is visible on right sleeve
- [ ] Colors match specifications (Green #4BA82E, Black #000000, White #FFFFFF)
- [ ] Image is clear and high quality
- [ ] Background is clean/neutral

## ⚠️ Important Notes

- **Copyright**: Ensure you have rights to use any images or designs
- **Brand Compliance**: Follow Škoda Auto brand guidelines
- **Consistency**: All three variants should have the same design, just different colors
- **Storage**: Once uploaded, images are stored permanently on the server
- **Replacement**: Uploading a new image replaces the previous one

## 💡 Tips for Best Results

1. **Consistency is Key**: Keep the same design across all color variants
2. **High Resolution**: Use the highest quality images possible
3. **Brand Accuracy**: Ensure Škoda GCC branding matches official guidelines
4. **Test First**: Upload one color variant and test before doing all three
5. **Backup**: Keep original high-resolution files for future updates
